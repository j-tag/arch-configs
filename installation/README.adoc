# Firewall

You may want to install a custom firewall like `nftables` specially in server environment. But keep in mind that `nftable` currently has many problems with `docker`.

# AUR Packages

You may also want to install these packages from AUR. This can be done after system installation also.

To install packages simply clone them using Git in a folder like `/opt/aur/` and then cd into their directory where there is a `PKGBUILD` file and run following command:

[source, shell]
makepkg -risc
