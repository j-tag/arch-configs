# Hesam's Arch Configs

This repo contains my personal and go-to configurations and packages on my Arch installs.

All of these configurations are tuned to meet my personal needs, you can use them however you want.

Also, I keep some useful commands here that may come in handy sometimes.

## What You'll Get

- Minimum possible packages
- A fully configured Arch Linux installation
- A fully configured KDE Plasma Desktop (Latest version)
- Fish shell out of the box
- Starship prompt out of the box
- Full configuration of the NVIDIA driver
- Dual boot with Windows for both systemd and GRUB bootloaders
- A bunch of useful [packages](https://github.com/j-tag/arch-configs/tree/main/installation)
- A bunch of useful [aliases](https://github.com/j-tag/arch-configs/blob/main/home/jtag/.config/fish/config.fish)
- A bunch of useful commands
